# PRD · 자격증 기반 공고 길잡이

> 4회차 · 2026-10-04 작성 · 5회차부터 클로드 코드가 이 문서를 읽고 만든다
> 갈 길 · A 새 서비스
> 서비스 주소 · https://job-guide-site.vercel.app/ (지금은 소개 페이지)

## 한 줄 소개
공공기관 인턴과 채용 공고에 지원하는 대학 재학생을 위해, 마감 전 공고 중 내 자격증, 전공, 경험을 우대하는 공고를 맨 위에 모아 보여 준다.

## 문제
공공기관 인턴이나 채용 공고에 지원하는 대학 재학생이, 내 자격증과 경험에 맞는 공고를 찾고 불합격 뒤 무엇을 더 쌓을지 정하다가, 공고와 후기와 공모전과 학회를 여러 곳에서 따로 찾아야 해서 불편하다.

## 대상
공공기관 인턴이나 채용 공고에 한 달에 3번 지원하는 대학 재학생

## 출발점 (3회차)
- 3회차에 만든 것 · 동선 대시보드 · https://travel-board-snowy.vercel.app/
- 아쉬웠던 점
  1. 대체할 수 있는 사이트와 앱이 있어서 굳이 쓸 필요를 못 느낀다
  2. 대시보드 디자인이 아쉽다
  3. 실제 사용 의도에 완전히 맞지 않는다
  4. 동선을 실제 도보와 대중교통 자료가 아니라 직선 거리로 정했다

## 이번에 만들 기능
**우대 공고 먼저 보기** · 내 자격증, 전공, 경험을 우대한다고 적힌 공고를 1순위로 보여 준다

### 동작 순서
1. 첫 화면에 "자격증", "전공", "경험" 입력 칸과 "고용형태" 선택(인턴, 정규직, 계약직)이 보인다
2. 칸을 채우고 "우대 공고 찾기" 버튼을 누른다
3. 공공기관 채용정보에서 고른 고용형태의 공고를 받아 오고, 마감일이 오늘 이전인 공고는 뺀다. 오늘 마감인 공고는 보인다
4. 공고에 적힌 우대사항과 내가 적은 자격증, 전공, 경험을 비교해, 하나라도 우대사항에 들어 있으면 "우대" 표시를 붙여 목록 맨 위에 보인다. 맞지 않는 공고는 그 아래에 보인다
5. 공고마다 기관 이름, 공고 제목, 고용형태, 마감일이 보인다
6. 공고를 누르면 원문 공고 페이지가 새 창으로 열린다
7. 목록 위에 "마지막으로 찾은 날: (날짜)"가 보이고, 화면 아래에 "자료 출처: 공공기관 채용정보 조회서비스(잡알리오, 공공데이터포털)"이 보인다. 입력한 스펙과 마지막으로 찾은 날짜는 이 기기에 남아서 새로고침해도 그대로다

### 쓰는 자료
- 공공기관 채용정보 조회서비스 (공공데이터포털, 잡알리오 자료). 공공기관 약 370곳의 공고
- 인증키는 공공데이터포털에서 받았다 (2026-10-04). 개발단계 하루 1,000회. .env 에 둔다
- 이용 조건 · 이용허락범위 제한 없음. 그래도 화면에 출처를 적는다

## 저장할 것 (6회차)
- 자격증 · 컴퓨터활용능력 1급
- 전공 · 경영학
- 경험 · 마케팅 동아리 활동
- 고용형태 · 인턴
- 마지막으로 찾은 날짜 · 2026-10-04

## 기록할 행동 (7회차)
- "우대 공고 찾기" 누르기 · 누를 때 1번
- 공고 원문 열기 · 공고를 누를 때 1번

## 성공 기준 (8회차)
기한 · 10월 4일 5회차 수업 끝
1. 내가 내 노트북 브라우저에서 "우대" 표시가 붙은 공고 3개의 원문을 열어, 내 자격증이나 전공이 우대 내용에 있는지 3분 안에 확인한다
2. 내가 내 노트북 브라우저에서 "우대 공고 찾기"를 눌러 30초 안에 "우대" 표시가 붙은 공고 목록을 보고, 그 목록에 마감일이 지난 공고가 하나도 없다

## 나중에 (지금은 안 만듦)
- 민간 기업 공고 더하기 · 사람인 오픈 API를 2026-10-04에 신청했고 승인을 기다린다. 하루 500회. 설명서에 우대사항 칸이 없어서 우대 비교가 될지 확인해야 한다
- 희망 근무기간으로 거르기 · "희망 근무 시작일"과 "희망 근무 종료일"을 넣으면 근무 기간 전체가 그 안에 드는 공고만 보인다. 근무 날짜가 없는 공고는 빼지 않고 "근무기간 확인 필요" 표시를 붙여 아래쪽에 보인다. 5회차 1시간에 조건이 너무 많아서 나중에 한다
- 내 스펙 입력 저장 화면 따로 두기 · 혼자서는 메모 앱과 차이가 작다
- 공고 찜 · 혼자서는 메모 앱과 차이가 작다
- 지원 기록과 합격 여부 체크 · 이 기기 저장으로 되지만 이번 기능을 먼저 만든다
- 공고별 자기소개서 작성과 저장 · 다른 공고 사이트에 바로 올리는 것은 그 사이트의 연결이 필요하다. 최종본 복사나 파일 저장 후 직접 올리는 방식부터 검토한다
- 공고별 네이버 블로그 후기 링크 · 검색 자료 출처가 정해지지 않았다
- 불합격 뒤 공모전과 학회 추천 (재학 대학 반영) · 공모전과 학회 자료 출처가 정해지지 않았다

## 아직 모르는 것
- 우대사항이 공고 목록 자료에 바로 들어 있는지, 공고 상세 자료를 따로 받아야 하는지
- 우대사항과 내 입력의 글자가 조금 다를 때(예: 컴활 1급과 컴퓨터활용능력 1급) 같은 것으로 볼지
- 응답에 우대조건, 고용형태, 접수기간이 실제로 들어 있는지. 공공데이터포털 페이지에는 항목 목록이 없고, 다른 사람의 프로젝트 설명으로만 확인했다
- 자료의 고용형태 구분이 인턴, 정규직, 계약직과 어떻게 맞는지
- 희망 근무기간 거르기를 하려면 자료에 근무 시작일과 종료일이 날짜로 들어 있는지
- 사람인 오픈 API 승인이 언제 나는지 (2026-10-04 신청함)
- 자소설닷컴 공고는 약관(제14조 제7항 2호, 9호, 제18조) 때문에 허락 없이는 쓰지 않는다. 제휴나 자료 제공 문의는 아직 안 했다
